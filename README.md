# One Letter: Coffee or Tea

One letter, and nothing else: **A** for coffee.

`main.py` (Python 3.13, standard library only) writes exactly one byte —
the letter `A` — to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`),
with a guard that the entry is exactly one non-whitespace character.

Why A: coffee is the more vivid stance — the ritual, the urgency, the
"don't talk to me before my coffee" energy — where tea reads calm and
polite. On the judge's criteria, vividness first, the bolder, more alive
answer wins the pairwise comparison.

Determinism: every run produces the same single byte (`A`,
sha256 `559aead08264d5795d3909718cdd05abd49572e84fe55590eef31a88a08fdffd`).
